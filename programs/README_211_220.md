# Compiler Design Programs 211–220

Ten standalone C11 educational examples added to the repository.

| No. | Program | Concept |
|---|---|---|
| 211 | `211_lexer_string_escape_checker.c` | Simple string-literal escape checking |
| 212 | `212_regex_character_class_union.c` | Union of ASCII character classes |
| 213 | `213_nfa_epsilon_reachability.c` | Epsilon closure of multiple NFA states |
| 214 | `214_grammar_first_first_conflict_pairs.c` | Pairwise FIRST/FIRST conflict reporting |
| 215 | `215_cfg_dominator_query.c` | Single-entry CFG dominator queries |
| 216 | `216_ir_dead_assignment_liveness.c` | Simplified dead assignment check |
| 217 | `217_register_interval_peak.c` | Sweep-line register pressure estimation |
| 218 | `218_tac_use_def_sets.c` | USE and DEF sets for a simple TAC instruction |
| 219 | `219_parser_parenthesis_depth.c` | Balanced-parentheses depth |
| 220 | `220_symbol_table_duplicate_scope.c` | Duplicate declarations in a lexical scope |

## Running the tests

```bash
bash tests/test_programs_211_220.sh
```

## Example

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/219_parser_parenthesis_depth.c -o depth
printf 'x+(y*(z+1))\n' | ./depth
```

All programs have intentionally restricted input domains for classroom use. Some examples model only one compiler operation rather than a full compiler pass. The supplied script tests representative cases only. GitHub C/C++ CI is not restored.
