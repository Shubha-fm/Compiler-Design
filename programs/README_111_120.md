# Programs 111–120

Ten standalone C11 teaching examples added to the Compiler Design collection.

| Number | Program | Concept |
|---|---|---|
| 111 | Lexical token line/column positions | Source location tracking |
| 112 | Longest operator recognition | Maximal munch for a fixed operator set |
| 113 | Regex postfix validator | Operator arity and expression stack |
| 114 | LL(1) FIRST/FIRST overlap | Detect common terminal in supplied sets |
| 115 | Parse-tree node counter | Simplified parenthesized notation |
| 116 | Interval addition | Static value-range analysis |
| 117 | CFG transitive reachability | Warshall algorithm |
| 118 | Strongly connected components | Kosaraju algorithm |
| 119 | IR variable swap | Three-address code temporary |
| 120 | Register pressure estimate | Peak overlap of live ranges |

## Running

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/118_cfg_strongly_connected_components.c -o scc
printf '3 3\n0 1\n1 0\n1 2\n' | ./scc
bash tests/test_programs_111_120.sh
```

The smoke tests cover one representative input per program. These restricted examples do not constitute production compiler analyses. Some tokenizers, grammars and IR programs recognize only specified simplified forms.
