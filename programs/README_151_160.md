# Compiler Design programs 151–160

Ten additional standalone C11 educational exercises.

| No. | Program | Concept |
|---|---|---|
| 151 | DFA language emptiness | BFS to an accepting state |
| 152 | DFA language finiteness | Reachable productive cycle test |
| 153 | Prefix expression validation | Binary operator arity |
| 154 | Useless grammar symbols | Fixed-example productive/reachable symbols |
| 155 | CFG edge classification | DFS tree, back, forward and cross edges |
| 156 | TAC to quadruple | Single expression conversion |
| 157 | Live interval lengths | Sum of half-open live range lengths |
| 158 | SSA phi-function demonstration | Two-branch merge example |
| 159 | Newline normalization | CRLF and CR to LF |
| 160 | Bytecode stack validation | Stack effects and invalid opcodes |

## Compile and test

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/151_dfa_empty_language.c -o dfa
printf '2 0\n0 1\n0 1\n1 1\n' | ./dfa
bash tests/test_programs_151_160.sh
```

Some programs use fixed examples, not arbitrary grammar or IR input. These tests are representative only, and test results should not be described as passing unless executed. The C/C++ CI workflow is intentionally not present.
