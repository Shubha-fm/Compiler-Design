# Compiler Design programs 301–305

Five standalone C11 educational programs extending the Compiler Design collection to **305 numbered programs**.

| No. | Program | Topic |
|---|---|---|
| 301 | [Lexer string escapes](301_lexer_string_escapes.c) | Validate a double-quoted ASCII string with common escape sequences |
| 302 | [Regex infix to postfix](302_regex_infix_to_postfix.c) | Shunting-yard conversion with precedence and grouping |
| 303 | [CFG cyclomatic complexity](303_cfg_cyclomatic_complexity.c) | Compute E − N + 2P using weak connected components |
| 304 | [TAC constant propagation](304_tac_constant_propagation.c) | Propagate known integer constants in straight-line three-address code |
| 305 | [Bytecode stack verifier](305_bytecode_stack_verifier.c) | Verify stack underflow and merge heights across control-flow edges |

## Run the checks

```bash
bash tests/test_programs_301_305.sh
```

## Compile one program

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/305_bytecode_stack_verifier.c -o stackcheck
printf '4\nPUSH\nPUSH\nADD\nHALT\n' | ./stackcheck
```

These are educational, bounded programs. The lexer handles one line and a small selection of escapes; the regular-expression converter uses explicit `.` concatenation and operands `a-z`; the CFG tool computes a graph measure rather than full basis-path analysis; constant propagation assumes straight-line single-letter variables and does not model signed overflow; and the bytecode verifier checks stack heights, not types, values, or all possible runtime errors. Programs may require valid structured input.

The test script provides ten sample checks. The C/C++ CI workflow remains removed.
