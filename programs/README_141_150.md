# Compiler Design programs 141–150

Ten additional standalone C11 educational programs.

| No. | File | Subject |
|---|---|---|
| 141 | `141_lexer_numeric_base.c` | Decimal, octal, hexadecimal literal classification |
| 142 | `142_regex_bracket_range.c` | Single-character regex range matching |
| 143 | `143_grammar_indirect_left_recursion.c` | Cycle detection in leading-nonterminal dependency graph |
| 144 | `144_dfa_reachable_state_count.c` | Binary DFA reachable states |
| 145 | `145_postfix_operand_count.c` | Postfix operand/operator count |
| 146 | `146_cfg_immediate_dominator.c` | Control-flow graph immediate dominators |
| 147 | `147_ir_constant_branch.c` | Constant branch simplification |
| 148 | `148_live_interval_overlap.c` | Half-open live range interference |
| 149 | `149_tac_instruction_counter.c` | Simple IR opcode counts |
| 150 | `150_type_conversion_rules.c` | Simplified C arithmetic type promotion |

## Compile and test

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/144_dfa_reachable_state_count.c -o dfa
printf '3 0 1 1 1 2 2\n' | ./dfa
bash tests/test_programs_141_150.sh
```

These are deliberately bounded teaching exercises. A single representative input per program is covered by the test script, not exhaustive validation. The previously removed C/C++ GitHub Actions workflow has not been reinstated.
