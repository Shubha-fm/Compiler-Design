# Compiler Design Programs 201–210

Ten new standalone C11 teaching programs.

| No. | Source | Topic |
|---|---|---|
| 201 | `201_lexer_tab_columns.c` | Source columns after tab expansion |
| 202 | `202_nfa_acceptance.c` | Epsilon-free NFA word acceptance |
| 203 | `203_grammar_nullable_sequence.c` | Nullability of a sequence of nonterminals |
| 204 | `204_ll1_table_lookup.c` | Predictive parse table lookup |
| 205 | `205_cfg_unreachable_blocks.c` | Unreachable control-flow blocks |
| 206 | `206_ir_copy_propagation.c` | Simplified single-copy TAC propagation |
| 207 | `207_peephole_push_pop.c` | Eliminate adjacent matching PUSH/POP operations |
| 208 | `208_live_interval_interference_matrix.c` | Register-interference matrix for live intervals |
| 209 | `209_ast_preorder.c` | Indexed AST preorder traversal |
| 210 | `210_ir_jump_threading.c` | Unconditional jump chaining and cycle detection |

## Compile and run

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/205_cfg_unreachable_blocks.c -o blocks
printf '4 2\n0 1\n1 2\n' | ./blocks
bash tests/test_programs_201_210.sh
```

These are deliberately restricted examples. The IR transformations assume pure operands and simplified instruction semantics. Examples include small fixed input bounds. The smoke tests contain one case per program; they are not exhaustive. The removed C/C++ GitHub Actions workflow is not reinstated.
