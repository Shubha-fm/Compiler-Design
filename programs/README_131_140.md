# Compiler Design programs 131–140

Ten additional standalone C11 examples for compiler construction labs.

| No. | Source | Topic |
|---|---|---|
| 131 | `131_token_stream_rle.c` | Run-length encoding of token classes |
| 132 | `132_regex_anchored_identifier.c` | Identifier-pattern recognition |
| 133 | `133_dfa_distinguishing_word.c` | Shortest distinguishing word for two DFAs |
| 134 | `134_grammar_cnf_checker.c` | Chomsky normal form rule check |
| 135 | `135_ll1_stack_trace.c` | Predictive LL(1) stack trace |
| 136 | `136_postfix_stack_peak.c` | Postfix evaluation stack pressure |
| 137 | `137_cfg_entry_exit_count.c` | Entry and exit nodes of control-flow graphs |
| 138 | `138_ir_label_duplicate_detection.c` | Intermediate-code duplicate labels |
| 139 | `139_dataflow_bitvector_union.c` | Bit-vector data-flow set operations |
| 140 | `140_three_address_constant_substitution.c` | Constant substitution in simple TAC |

## Compile and test

```sh
gcc -std=c11 -Wall -Wextra -pedantic programs/136_postfix_stack_peak.c -o postfix
echo 'ab+c*' | ./postfix
bash tests/test_programs_131_140.sh
```

These are bounded educational examples, not complete compiler phases. The supplied tests check one sample per program and are not exhaustive. The GitHub Actions C/C++ CI workflow remains removed; tests must be run manually.
