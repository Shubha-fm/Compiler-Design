# Compiler Design programs 121–130

Ten new standalone C11 teaching programs.

| No. | Program | Topic |
|---|---|---|
| 121 | NFA epsilon closure | Graph-based closure traversal |
| 122 | DFA equivalence | Product-state BFS for binary automata |
| 123 | LL(1) conflict check | Supplied FIRST/FOLLOW sets and nullable flags |
| 124 | Dangling-else binding | Nearest unmatched if convention |
| 125 | Postfix constant evaluator | Small expression evaluation |
| 126 | Constant-copy environment | Straight-line data-flow demonstration |
| 127 | Natural loop detection | Back-edge predecessor closure, assuming domination |
| 128 | Shortest DFA accepted word | BFS and predecessor reconstruction |
| 129 | Token histogram | Simplified identifiers, integers, and punctuation |
| 130 | IR label resolution | Resolve symbolic jump targets |

## Build and test

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/121_nfa_epsilon_closure.c -o closure
printf '3 2 0\n0 1\n1 2\n' | ./closure
bash tests/test_programs_121_130.sh
```

These programs use simplified grammars and small bounded data structures. The test script has ten representative checks, not exhaustive verification. The C/C++ CI workflow is intentionally absent.
