# Compiler Design Programs 171–180

Ten additional standalone C11 teaching examples.

| No. | Example | Topic |
|---|---|---|
| 171 | `171_lexer_comment_counter.c` | Line and block comments outside quotations |
| 172 | `172_dfa_shortest_rejecting_word.c` | BFS shortest rejecting DFA word |
| 173 | `173_grammar_first_sequence.c` | FIRST of symbol sequence, supplied FIRST/nullable |
| 174 | `174_cfg_bridge_detection.c` | Bridges in the undirected graph underlying a CFG |
| 175 | `175_ast_node_height.c` | AST height by recursion |
| 176 | `176_tac_algebraic_identities.c` | Simplified TAC algebraic identities |
| 177 | `177_register_interval_coloring.c` | Greedy interval register allocation |
| 178 | `178_code_alignment.c` | Power-of-two instruction alignment |
| 179 | `179_lr_action_table_validator.c` | LR ACTION table conflict detection |
| 180 | `180_cfg_edge_split_plan.c` | Plan CFG critical-edge splits |

## Compile and test

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/179_lr_action_table_validator.c -o actioncheck
printf '2\n0 a s1\n0 a r2\n' | ./actioncheck
bash tests/test_programs_171_180.sh
```

Programs are educational and restricted to specified formats. Tests use representative cases, not exhaustive correctness checks. No GitHub Actions C/C++ CI is installed.
