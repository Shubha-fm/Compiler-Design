# Compiler Design Programs 181–190

Ten new educational C11 exercises.

| Number | Program | Topic |
|---|---|---|
| 181 | `181_lexer_nested_comment_warning.c` | Identify nested openers in simplified C block comments |
| 182 | `182_dfa_state_partition.c` | Partition refinement for binary DFA equivalence classes |
| 183 | `183_regex_escape_validator.c` | Validate a small regex escape alphabet |
| 184 | `184_grammar_left_factoring_prefix.c` | Common prefix of two production alternatives |
| 185 | `185_cfg_cyclomatic_complexity.c` | Graph-based cyclomatic complexity |
| 186 | `186_tac_common_subexpression.c` | Illustrative local common subexpression reuse |
| 187 | `187_ast_postorder.c` | Binary AST postorder traversal |
| 188 | `188_ir_constant_comparison.c` | Simplify constant comparisons |
| 189 | `189_graph_reverse_postorder.c` | CFG reverse DFS postorder |
| 190 | `190_codegen_load_store.c` | Basic pseudo-assembly generation |

## Run the sample checks

```bash
bash tests/test_programs_181_190.sh
```

## Compile one program

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/190_codegen_load_store.c -o codegen
echo "value 42" | ./codegen
```

The programs are learning examples with restricted input formats. In particular, program 186 assumes no changes to source operands between matching expressions. Program 185 uses an undirected connected-component count while counting supplied directed edges. Tests cover examples, not full correctness. GitHub C/C++ CI remains removed.
