# Programs 231–240: Compiler Design in C

Ten standalone educational programs in standard C11.

| No. | File | Teaching objective |
|---|---|---|
| 231 | `231_postfix_to_infix.c` | Reconstruct a fully parenthesized infix expression |
| 232 | `232_grammar_nullable_solver.c` | Solve nullable nonterminals by fixed-point iteration |
| 233 | `233_dfa_shortest_state_path.c` | Find the shortest binary word reaching a DFA state |
| 234 | `234_nfa_epsilon_move.c` | Apply an epsilon-expanded NFA transition |
| 235 | `235_grammar_dependency_toposort.c` | Topologically order grammar dependencies |
| 236 | `236_cfg_backedge_dominance.c` | Identify loop back edges through dominance |
| 237 | `237_ir_commutative_cse.c` | Recognize commutative common subexpressions |
| 238 | `238_bytecode_stack_safety.c` | Check stack heights across an acyclic bytecode CFG |
| 239 | `239_symbol_table_scope_stack.c` | Enter/exit scopes, declare symbols, and resolve names |
| 240 | `240_assembly_basic_block_labels.c` | Identify basic-block leaders in branch bytecode |

## Run sample tests

```bash
bash tests/test_programs_231_240.sh
```

## Compile an example

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/232_grammar_nullable_solver.c -o nullable
printf '4\nS AB\nA -\nB C\nC -\n' | ./nullable
```

**Scope:** The programs are small, bounded teaching examples. The NFA/grammar representations use single-character symbols. Program 237 assumes pure expressions and unmodified operands. Program 238 handles only acyclic CFGs and requires consistent stack depths at merges. No example is a full compiler implementation. The sample tests are not exhaustive, and the removed C/C++ GitHub Actions workflow has not been reinstated.
