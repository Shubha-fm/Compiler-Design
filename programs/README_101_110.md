# Compiler Design Programs 101–110

Ten standalone C11 educational examples.

| Program | Topic |
|---|---|
| 101 | Levenshtein edit distance for syntax suggestions |
| 102 | Simplified C integer suffix recognition |
| 103 | UTF-8 byte sequence structure classification |
| 104 | Direct left recursion detection |
| 105 | DFA transition trace modulo five |
| 106 | Compile-time comparison simplification |
| 107 | Stack depth and underflow analysis |
| 108 | Topological ordering of a DAG |
| 109 | Variable interference edges for one live set |
| 110 | Simple three-address code validation |

## Compile and run

```bash
gcc -std=c11 -Wall -Wextra -pedantic programs/107_stack_depth_analyzer.c -o stack
printf 'PUSH PUSH POP\n' | ./stack
bash tests/test_programs_101_110.sh
```

The examples are intentionally limited and not general-purpose compiler implementations. In particular, the UTF-8 example checks byte structure rather than full Unicode scalar validity. The test script provides one smoke test per program; it is not exhaustive.
