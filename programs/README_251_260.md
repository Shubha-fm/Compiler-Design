# Compiler Design C Programs 251–260

These ten standalone C11 examples cover a lexer transformation, finite automata, parsing tables, control-flow analysis, data flow, register allocation, and assembler/bytecode validation.

| No. | Program | Description |
|---|---|---|
| 251 | `251_lexer_strip_comments.c` | Remove line and block comments while preserving quoted literals |
| 252 | `252_dfa_minimize_partition_count.c` | DFA equivalence classes using distinguishability table filling |
| 253 | `253_nfa_epsilon_acceptance.c` | NFA acceptance with epsilon-closure after each transition |
| 254 | `254_ll1_table_conflict_builder.c` | Detect conflicts between supplied LL(1) SELECT sets |
| 255 | `255_cfg_immediate_postdominator.c` | Immediate postdominators in a single-exit graph |
| 256 | `256_available_expressions.c` | Forward must-analysis of available expression bitsets |
| 257 | `257_ir_algebraic_simplifier.c` | Algebraic identities on one TAC operation |
| 258 | `258_greedy_register_spill.c` | Greedy interference graph coloring with spills |
| 259 | `259_assembler_two_pass_labels.c` | Two-pass symbolic label resolution |
| 260 | `260_bytecode_stack_depth_merge.c` | Stack-height and underflow checks in a DAG |

## Build and run

```bash
bash tests/test_programs_251_260.sh
gcc -std=c11 -Wall -Wextra -pedantic programs/259_assembler_two_pass_labels.c -o assembler
printf 'LABEL start\nNOP\nJMP start\nHALT\nEND\n' | ./assembler
```

**Limitations:** These are bounded educational examples rather than full compiler implementations. DFA equivalence-class counting includes unreachable states. Program 255 requires every node to reach the specified exit. Program 256 requires a fully reachable CFG. Program 257 assumes pure integer expressions. Program 258 uses vertex-order greedy coloring and does not guarantee a minimal spill count. Program 260 requires an acyclic CFG; all supplied vertices participate in the topological check. The test script includes ten sample checks but is not comprehensive verification. C/C++ CI stays removed.
