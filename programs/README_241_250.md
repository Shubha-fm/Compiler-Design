# Compiler Design Programs 241–250

Ten additional standalone C11 teaching programs.

| No. | Source | Topic |
|---|---|---|
| 241 | `241_lexer_identifier_spans.c` | Identifier recognition with byte offsets |
| 242 | `242_regex_repeat_bounds.c` | Enumerate one-character bounded repetitions |
| 243 | `243_dfa_product_reachability.c` | Product-DFA reachable state counting |
| 244 | `244_grammar_productive_solver.c` | CFG productive-symbol fixed point |
| 245 | `245_ll1_stack_parser.c` | Predictive parsing of balanced parentheses |
| 246 | `246_cfg_edge_profile.c` | Edge-frequency profiling from a block trace |
| 247 | `247_constant_lattice_meet.c` | Constant-propagation lattice meet |
| 248 | `248_ssa_phi_arity.c` | Phi operand count versus CFG predecessors |
| 249 | `249_interference_degree.c` | Register-interference graph vertex degrees |
| 250 | `250_linker_relocation_resolver.c` | Simplified absolute symbol relocation |

## Compile and test

```bash
bash tests/test_programs_241_250.sh
gcc -std=c11 -Wall -Wextra -pedantic programs/245_ll1_stack_parser.c -o ll1
printf '(()())\n' | ./ll1
```

**Limitations:** These are bounded educational examples, not production compilers. Program 241 counts byte offsets rather than Unicode character positions. Program 242 supports one-character repetition only. Program 245 recognizes a single fixed grammar. Program 247 implements a simple lattice meet, not a complete propagation pass. Program 250 supports only absolute 32-bit word relocations. Arithmetic overflow, complete language syntax, and malformed-input recovery are outside the scope of several examples. Each sample test checks one representative input and is not a proof of correctness.

The removed GitHub Actions C/C++ CI workflow has not been reintroduced.
